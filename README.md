## Task 3 – Basic Calculator

**Project Name:** Basic Calculator
**Description:** A fully functional calculator that performs basic arithmetic operations such as addition, subtraction, multiplication, and division. The project focuses on JavaScript logic, DOM manipulation, and responsive UI design using CSS Grid.
**Technologies Used:** HTML, CSS (Grid), JavaScript
**Features:**

* Interactive buttons for numbers and operators
* Display screen for input and output
* Error handling for invalid expressions

**Preview:**
Open `index.html` in a browser or access the live demo via GitHub Pages.
